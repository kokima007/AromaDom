# Арома Дом

Учебный проект ASP.NET Core Razor Pages (.NET 10) и SQLite.

Запуск из корня репозитория: `dotnet run --project Source/AromaDom.csproj`. Откройте http://localhost:5084. При отсутствии базы приложение создаст её из SQL-скриптов.

1. **База данных.** Схема в 3НФ, внешние ключи, импорт пяти исходных таблиц. В базе 18 материалов, 14 изделий и 73 строки рецептур. Скрипты и ER-диаграмма находятся в `Source/Database`. Диаграмма построена из метаданных SQLite.
2. **Каталог.** Карточки материалов с остатками, ценой и суммарным расходом по рецептурам. Округление до сотых выполняется после сложения.
3. **Редактирование.** Добавление и изменение материала с проверкой полей, сохранением в БД и уведомлениями.
4. **Интеграция.** Кнопка «Продукция» открывает список изделий с расходом материала на единицу. Кнопка «Расчёт выпуска» открывает калькулятор. Метод `ProductionCalculator.Calculate` возвращает целое число изделий или −1 при некорректных параметрах.

Калькулятор делит количество сырья после вычета процентных потерь на произведение двух параметров изделия и коэффициента типа продукции. Итог округляется вниз. Нулевое количество сырья даёт 0. Например, из 100 единиц сырья при потерях 0,12 %, коэффициенте 1 и параметрах 2 и 3 получается 16 изделий.

Готовую сборку создаёт `dotnet publish Source/AromaDom.csproj -c Release -o Run`. Для запуска из папки Run выполните `dotnet AromaDom.dll --urls http://localhost:5084`. Нужна среда ASP.NET Core 10.

Фирменный логотип и иконка отсутствовали в предоставленных ресурсах.
